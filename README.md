# DCR Reporting Services Dashboard

This project presents an example of the **reporting services offered by DCR**.  
It demonstrates how our team can deliver clear, interactive, and reproducible reports using **R** and **Quarto**.

The page serves as a showcase of our reporting capabilities.

---

## Technical Details

- **Built with:** R and Quarto  
- **Visualizations:** Plotly & ggplot2  
- **Hosted on:** GitHub Pages (`/docs` folder)
